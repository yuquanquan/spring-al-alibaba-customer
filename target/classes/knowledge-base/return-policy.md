# 智能客服系统 - 退货政策

## 1. 退货条件

以下情况支持退货退款：
- 商品自购买之日起 **7天内** 可申请无理由退货
- 商品存在质量问题，**30天内** 可申请退货
- 商品与描述不符，**15天内** 可申请退货
- 商品在运输过程中损坏，签收后 **48小时内** 可申请退货

以下情况 **不支持** 退货：
- 超过退货时限
- 虚拟商品（如软件授权、云存储服务）已激活使用
- 定制类商品（如私有化部署方案）
- 商品已使用且非质量问题

## 2. 退货时限

| 场景 | 退货时限 | 起算时间 |
|------|---------|---------|
| 无理由退货 | 7天 | 签收次日 |
| 质量问题退货 | 30天 | 签收次日 |
| 描述不符退货 | 15天 | 签收次日 |
| 运输损坏退货 | 48小时 | 签收时间 |

## 3. 退款金额

退款金额计算规则：
- **全额退款**: 商品未使用、包装完好，退还全部支付金额
- **部分退款**: 商品有轻微使用痕迹，退还支付金额的80%
- **不予退款**: 商品已大量使用或损坏，不予退款
- 优惠券和折扣金额不参与退款计算
- 退款不包含运费（除非是卖家责任导致的退货）

## 4. 退货流程

### 第1步: 提交退货申请
- 登录系统 → 我的订单 → 选择需要退货的订单
- 点击「申请退货」按钮
- 选择退货原因，填写退货说明（选填，但建议详细描述问题）
- 上传相关照片（如有质量问题，请拍照取证）

### 第2步: 填写退货表单
- 确认退货商品信息
- 选择退款方式（原路退回 / 退至账户余额）
- 确认退货地址（系统将自动提供退货地址）

### 第3步: 商家审核
- 系统自动通知商家，商家在 **1-3个工作日** 内审核
- 审核通过：系统发送退货地址和退货单号
- 审核拒绝：可修改申请或联系客服协商

### 第4步: 寄回商品
- 按照系统提供的退货地址寄回商品
- 务必在包裹中附上退货单号
- 建议使用有追踪号的快递方式
- 保留快递单号以便查询

### 第5步: 退款处理
- 商家收到退货商品后进行验收（1-2个工作日）
- 验收通过后，退款将在 **1-5个工作日** 内到账
- 退款到账后会发送短信/邮件通知

## 5. 运费说明

| 退货原因 | 运费承担方 | 说明 |
|---------|-----------|------|
| 商品质量问题 | 卖家 | 卖家提供退货运费补贴 |
| 商品描述不符 | 卖家 | 卖家全额承担运费 |
| 运输损坏 | 物流公司 | 由物流保险理赔 |
| 无理由退货 | 买家 | 买家自行承担退货运费 |
| 买家个人原因 | 买家 | 买家承担来回运费 |

## 6. 换货政策

- 支持换货的场景：商品质量问题、发错商品
- 换货时限：签收后7天内
- 换货流程：申请换货 → 审核通过 → 寄回原商品 → 发出新商品
- 换货不额外收取运费（卖家承担来回运费）

## 7. 注意事项

1. 请保留商品原包装、标签和所有配件
2. 退货商品需保持完好，不影响二次销售
3. 退货时请将所有配件和赠品一并退回
4. 请妥善包装退货商品，避免运输过程中二次损坏
5. 如使用非指定快递公司寄回，丢失风险由买家承担
6. 退货进度可在「我的订单 → 退货记录」中实时查看
